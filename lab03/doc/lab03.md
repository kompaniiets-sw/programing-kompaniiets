### 3. Розробка програми

У `src/main.c` розробили програму. Умова та по-пунктне виконання задокументовані у коментарі до коду. Обчислення виконується за формулою:

```C
decimal = d3 * p^3 + d2 * p^2 + d1 * p^1 + d0 * p^0
```

Програма:

1. вводить основу `p` та перевіряє її на діапазон `[2..10]`;
2. вводить розряди `d3..d0` і перевіряє, що кожен лежить у `[0..p-1]`;
3. обчислює та виводить результат.

При некоректних даних виводиться повідомлення і повертається код `1`.

### 4. Точка входу

**Точка входу** — функція `int main(void)` у `src/main.c`. Операційна система через стартовий код передає керування саме їй, а повернене нею значення стає **кодом завершення** програми.

**Чому точка входу одна?** Щоб ОС і компонувальник однозначно знали, з якого місця починати виконання:

- кілька `main` → помилка багаторазового визначення;
- відсутність `main` → помилка невизначеного символу.

### 5. Заміна `scanf` на `fgets` + `strtol`

Спочатку для введення використали `scanf`, але `clang-tidy` зупинив збірку з помилкою `cert-err34-c`: `scanf` **не повідомляє про помилки перетворення**. Замінили його функцією `read_int`:

```c
static int read_int(const char *prompt, int *out)
{
    char buf[64];
    char *end = NULL;
    long val = 0;

    printf("%s", prompt);
    if (fgets(buf, sizeof buf, stdin) == NULL) {
        return 0;
    }
    errno = 0;
    val = strtol(buf, &end, 10);
    if (end == buf || errno != 0 || val < INT_MIN || val > INT_MAX) {
        return 0;
    }
    /* ... перевірка зайвих символів після числа ... */
    *out = (int)val;
    return 1;
}
```

Функція відхиляє нечислове введення, зайві символи та значення поза межами `int`, тому кожен розряд вводиться з нового рядка.

## Контрольні запитання

**1. З яких розділів складається програма мовою С?**

Програма мовою C складається з директив препроцесора (`#include`, `#define`), глобальних оголошень (типів, констант, змінних, прототипів функцій) та визначень функцій, серед яких обов'язковою є головна функція `main`. Також програма містить коментарі, які пояснюють код.

**2. Який алгоритм називається лінійним?**

Лінійним називається алгоритм, у якому всі дії виконуються **послідовно**, одна за одною і лише по одному разу, без розгалужень і циклів.

**3. Запишіть усі можливі оператори, які дозволять значення змінної a збільшити на одиницю.**

Збільшити значення змінної `a` на одиницю можна операторами `a++;` `++a;` `a += 1;` та `a = a + 1;`

**4. Що таке «проєкт»?**

Проєкт — це набір файлів (вихідний код, `Makefile`, документація), з яких збирається одна програма.

**5. Який порядок створення нового порожнього проєкту?**

Спочатку створюють каталог проєкту з підкаталогами `src` та `doc`, потім додають файл `src/main.c` з функцією `main`, файли `Makefile` і `README.md`. Після цього проєкт розміщують у клонованому репозиторії Git.

**6. Як виконати збірку програми?**

Збірка виконується командою `make all` (збірка разом із перевірками `clang-format` та `clang-tidy`) або `make compile`. Результатом є виконуваний файл `dist/main.bin`.

**7. Який порядок додавання нового файлу до проєкту?**

Новий файл створюють у каталозі `src`, підключають його заголовок директивою `#include` і додають до `Makefile` (наприклад, `LAB_OPTS = -I./src src/lib.c`). Потім файл додають до Git командою `git add`.

**8. Як виправити помилку у програмі?**

Спочатку читають повідомлення компілятора, яке вказує файл і рядок помилки, виправляють код і перезбирають проєкт. Логічні помилки знаходять за допомогою відлагоджувача: ставлять breakpoints, виконують програму покроково командою `next` і переглядають змінні командою `frame variable`.

**9. Як поставити програму на виконання?**

Програму запускають командою `make run` (збірка та запуск) або безпосередньо командою `./dist/main.bin`.

**10. Чим консольні програми відрізняються від віконних програм?**

Консольна програма працює в терміналі з текстовим введенням і виведенням та виконується послідовно. Віконна програма має графічний інтерфейс (вікна, кнопки, меню) і працює за принципом **обробки подій**, що надходять від користувача.

**11. Чим змінна відрізняється від константи?**

Значення змінної можна змінювати під час виконання програми, а значення константи (`const` або `#define`) задається один раз і далі не змінюється.

**12. Чим відрізняється префіксний запис операції інкременту від постфіксного запису?**

У префіксному записі `++a` значення змінної спочатку збільшується, а потім використовується у виразі. У постфіксному записі `a++` у виразі використовується старе значення, а збільшення відбувається після цього. Наприклад, при `a = 5` вираз `b = ++a;` дає `a = 6` і `b = 6`, а `b = a++;` дає `a = 6` і `b = 5`.
